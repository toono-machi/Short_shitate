# ショート仕立て — SOUND SHORT EDITOR

フル尺の曲から**中間部分を削除し、前半と後半を自然につないでショート版を作る**、ブラウザ完結の音声編集アプリです。

元の「ループ仕立て」のチョコレート×バニラのデザイン・波形操作・クロスフェード・WAV/MP3書き出しを応用しています。**曲はループしません**。冒頭から末尾までの1つの短い楽曲を制作します。

## 構成

- `index.html`：GitHub Pages公開用の画面
- `style.css`：スタイル
- `app.js`：音声処理、描画、操作、書き出し
- `Short_shitate_single.html`：**単一ファイルで動く版**。こちらだけを開いても使用できます。

## 操作

1. `index.html` または `Short_shitate_single.html` をブラウザで開く。
2. WAV / MP3 / M4Aなど、ブラウザがデコードできる音声ファイルを読み込む。
3. 波形の**緑のCUT IN**を「前半をここまで残す位置」に、**オレンジのCUT OUT**を「後半をここから使う位置」に移動。真ん中の薄赤色の部分が削除される。
4. 必要なら15 / 30 / 45 / 60 / 90 / 120秒、または任意秒数のプリセットを使っておおまかなカット位置を配置する。
5. 数値入力、±0.01秒ボタン、拡大波形で微調整。紫色のカーソルは全体波形をクリックして設定でき、各マーカーにも反映可能。
6. クロスフェードを0〜最大5秒の範囲で調整。長さは前半・後半の長さにより制限される。リニア/イコールパワーを選択可能。
7. 「元のフル尺」「ショート版を試聴」「つなぎ目だけ」で再生確認。再生・一時停止・シーク・停止に対応。**1回再生すると終了**する。
8. WAVまたはMP3で個別保存、複数曲はZIPで一括保存。出力名は元のファイル名に `_short` を付けたもの。

### 拍に合わせる（オプション）

BPMを手動入力し「マーカーを拍にスナップ」にチェックすると、全体波形でカットマーカーをドラッグした際に設定拍数ごとのグリッドへ吸着します。曲頭を拍の原点（0秒）として計算するため、実際のビート位置がずれる曲では使用せず、耳で合わせてください。BPM自動判定はしません。数値入力と拡大波形操作はスナップしないので、微調整が可能です。

## 接続方法（ループ編集との違い）

全音声が `T` 秒、カット開始が `A` 秒、カット終了が `B` 秒、クロスフェードが `F` 秒の場合：

- 前半 `0〜A` 秒を使用。
- 中間 `A〜B` 秒を削除。
- 後半 `B〜T` 秒を使用。
- 前半の最後の `F` 秒と、後半の最初の `F` 秒を重ねて滑らかに接続。
- 出力は `A + (T-B) - F` 秒になります。

処理はサンプル単位で行い、リニアフェードまたはイコールパワーフェードを適用します。重ね合わせでピークが1.0を超える場合は出力全体の音量を下げてクリッピングを避けます。

**重要：** 自然な音楽的接続には、前半と後半のリズム、コード、旋律、歌詞、フレーズが噛み合う場所を選ぶ必要があります。クロスフェードだけで拍・調性・歌詞を自動補正するものではありません。

## 動作・保存条件

- **WAV保存**：16bit PCM。インターネットなしで可能。
- **MP3保存**：192 / 256 / 320 kbps。エンコード時に `lamejs` をCDNから取得するためインターネットが必要。
- **サンプルレート**：デコードされた音声のサンプルレート / 44,100Hz / 48,000Hz を選択可能。ブラウザによっては音声のデコード時に自動的にリサンプリングされるため、「読み込み時」の値は元ファイルのヘッダー値とは限りません。
- 対応チャンネル：モノラル/ステレオ。
- 読み込みは1ファイル250MBまで。一括ZIPは100曲まで、4GB以下。
- 読み込んだ音声は外部へ送信しません（MP3ライブラリのダウンロードは行います）。音声データと編集設定はブラウザを閉じると失われます。
- 最近のChrome/Edgeなど、Web Audio API対応ブラウザでの利用を推奨。

## GitHub Pages公開

1. 新規リポジトリを作る。
2. `index.html`・`style.css`・`app.js`を同じディレクトリにアップロード。
3. GitHubの `Settings > Pages` でブランチの `main / (root)` から公開する。

公開ファイルを1つにしたい場合は、単体版 `Short_shitate_single.html` を `index.html` にリネームしてアップロードしても利用できます。

Chromiumで以下を確認済み：WAV/MP3の読み込み、ショート尺プリセット、マーカーのドラッグ、BPMスナップ、クロスフェード変更、継ぎ目試聴、停止・一時停止・再開、WAV保存、複数音源のZIP一括保存、スマホ幅の表示。
